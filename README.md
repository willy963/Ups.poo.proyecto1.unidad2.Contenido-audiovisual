# Ups.poo.proyecto1.unidad2.Contenido-audiovisual
Proyecto de contenido audiovisual donde se emplea varios tipos de tipos audiovisuales para generar nuevas clases, asociaciones, herencias, etc. para generar una catalogo informativo de las clases principales de contenido.
-	Los objetivos y propósito del proyecto.
Implementar mejoras a un proyecto con clases de Contenido Audiovisual en Java utilizando técnicas y conceptos de Programación Orientada a Objetos (POO), tales como herencia, asociación, agregación, y composición. Para ello se amplía el número de clases y se va modificando y ajustando para que el proyecto acepte varios tipos de clases tanto las previas como las que se asigna como nuevas sin producir errores y tener un funcionamiento adecuado.
-	Las clases y funcionalidades nuevas que has añadido.
Las clases son la base del funcionamiento del proyecto ya que nos permiten definir características, datos y valores que necesitamos. Pare el proyecto contaremos con 2 grupos de clases: las implementadas en el proyecto previa modificación y las que iremos agregando según las peticiones del proyecto en ejecución y sus requerimientos.
Clases Predefinidas: Película, Serie de TV y Documental
Clases agregadas para mejorar el funcionamiento y clasificación de los datos: 
Actor (asociada a película), Temporada (asociada a Serie de TV), Investigador (Asociada a Documental). Además 2 clases nuevas propuestas aparte de las peticiones y que tendrán herencia de Contenido Audiovisual que serán: Videojuegos y Videopodcast.
-	Instrucciones para clonar y ejecutar el proyecto.
Para la clonación y ejecución del proyecto se necesita descargar el archivo zip o implementar mediante la URL desde github.
-	Mejora adicional 
Se mejoró el uso de las clases y la clasificación de las clases bases para poder incluir más información acerca de los datos de los contenidos audiovisuales solicitados, además de 2 nuevas clases de contenido audiovisual nuevas propuestas a criterio propio que son: Videojuegos y Videopodcast, las cuales fueron implementadas con éxito en la prueba del código.
